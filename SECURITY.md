# Security Policy

## Supported Versions

Only the latest release of Simplistic Tetris receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

Use GitHub's private vulnerability reporting:
👉 [Report a vulnerability](https://github.com/KevOneRedOne/Simplistic-Tetris/security/advisories/new)

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

### Response timeline

| Step | Timeframe |
|------|-----------|
| Acknowledgement | Within 48 hours |
| Assessment | Within 7 days |
| Fix & release | Depends on severity |

Security fixes are released as patch versions and disclosed in the [CHANGELOG](./CHANGELOG.md).
